# Sources and provenance

Official documentation consulted on 2026-10-20:

- SEC EDGAR APIs: https://www.sec.gov/search-filings/edgar-application-programming-interfaces
- SEC developer access guidance: https://www.sec.gov/about/developer-resources
- FRED observations endpoint: https://fred.stlouisfed.org/docs/api/fred/series_observations.html
- FRED API keys: https://fred.stlouisfed.org/docs/api/api_key.html
- DEXUSEU series and unit: https://fred.stlouisfed.org/series/DEXUSEU
- FEDFUNDS series and frequency: https://fred.stlouisfed.org/series/FEDFUNDS

SEC public data APIs do not require an API key. Follow their access requirements and identify your application/contact. FRED API requests require a registered key. Review each provider's current terms before distributing downloaded live data.

The delivered examples contain only generated fictional observations. No live company values or live economic measurements are represented as verified in this release. Live responses are saved locally when the user runs live mode successfully. Raw hashes record content integrity, not independent proof that a source's figures are correct.
